# Bakery Data Analysis Project

## Objective
Analyze bakery sales data to understand customer behavior and improve business performance.

## Tools Used
- Python (Pandas, Matplotlib)
- Power BI
- Jupyter Notebook

## Key Insights
- Morning (8–11 AM) has highest sales
- Coffee, bread, and tea are top products
- Customers buy multiple items per order
- Weekday sales are higher than weekends

## Files Included
- Report (PDF)
- PPT Presentation
- Data Cleaning Code
- EDA Notebook
- Dataset
- Power BI Dashboard

## Conclusion
This project helps in understanding sales trends and improving business decisions using data analytics.
